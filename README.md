# 🛡️ Tugas Keamanan Sistem Informasi dan Jaringan

## 📘 Deskripsi Tugas

Tugas ini bertujuan untuk menguji pemahaman dan keterampilan mahasiswa dalam menerapkan prinsip-prinsip dasar keamanan informasi dan keamanan jaringan. Mahasiswa diminta untuk mengimplementasikan salah satu metode kriptografi klasik dan menganalisis cara kerja algoritma tersebut dalam konteks perlindungan data.

## 🧩 Topik Utama

- **Kriptografi Klasik**: Implementasi algoritma Hill Cipher menggunakan Python dan NumPy.
- **Transformasi Data**: Konversi plainteks ke bentuk numerik, pengolahan blok, enkripsi dengan matriks kunci, dan pembentukan ciphertext.
- **Keamanan Data**: Memahami pentingnya kunci rahasia dan bagaimana proses enkripsi dapat melindungi integritas dan kerahasiaan informasi.
- **Penguatan Konsep**: Penerapan aljabar linear dalam kriptografi serta studi kasus tentang kelemahan dan kekuatan cipher klasik.

## 🎯 Tujuan Pembelajaran

- Menjelaskan konsep dasar enkripsi dan dekripsi data.
- Mengimplementasikan metode Hill Cipher dalam bahasa pemrograman Python.
- Menggunakan operasi matriks dan mod 26 untuk memproses data.
- Memahami pentingnya validasi input dan keamanan kunci.
- Menginterpretasikan hasil enkripsi dalam bentuk teks dan numerik.
